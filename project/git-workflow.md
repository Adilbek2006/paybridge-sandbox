# Git Workflow

## Branch naming

One branch per task: DIP-<number>-short-description
Example: DIP-8-requirements

## Commit messages

Format: DIP-<number>: short description of what was done
Example: DIP-8: Add functional and non-functional requirements

## Pull Requests

- Every change goes through a PR to main
- The other team member reviews before merge
- Leave at least one comment or question in the review
- Link the PR to the YouTrack task

## Rules

- Each person commits only from their own GitHub account
- Never commit .env or API keys — use .env.example with placeholders
- Tags for submissions: prob-period-1, pre-defense-1, pre-defense-2, final-pre-defense
